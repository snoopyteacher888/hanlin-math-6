# 數學六上學習樂園（翰林版）

四德學輔班學習樂園的六年級數學。學生回家用來「玩著複習」，每個單元只練最常錯的重點（依翰林版六上評量類題整理）。

網址：https://snoopyteacher888.github.io/hanlin-math-6/

## 程式在哪裡改
三、五、六年級的數學網站用**同一套程式**，只有 `js/site.js`（年級）和這個 README 不一樣。
- 遊戲、題目、樣式都在 [`nani-math-3`](https://github.com/snoopyteacher888/nani-math-3) 修改。
- 六年級的題目在 `js/questions56.js` 的 `G6`。
- 改好後在 `nani-math-3` 執行 `bash tools/sync.sh`，再到這個 repo commit。
- 遊戲玩法、注音、手機版／網頁版、說明頁的說明，請看 `nani-math-3` 的 README。

六年級預設不加注音（地圖上可以打開）；紀錄只存在這台裝置的瀏覽器。
